# alibekov.pro — хаб программ Тимура Алибекова

Статичный сайт без сборки и зависимостей (шрифты — Google Fonts по CDN). Деплой: GitHub Pages из `main`.

## Структура

| Адрес | Файл | Что это |
|---|---|---|
| `/` | `index.html` | Хаб: два раздела — «Для себя» и «Для бизнеса», по две программы в каждом |
| `/seminar/` | `seminar/index.html` | Тренинг «Хватит ли вам денег на всю оставшуюся жизнь?» (3 900 ₸ / 9 990 ₸ с игрой) |
| `/lichnoe-soprovozhdenie/` | `lichnoe-soprovozhdenie/index.html` | «Личное сопровождение» — пакеты 19/39/79 тыс. ₸ в месяц |
| `/biznes-soprovozhdenie/` | `biznes-soprovozhdenie/index.html` | «Бизнес-сопровождение» — пакеты 49/99/199 тыс. ₸ в месяц |
| `/umny-magazin/` | `umny-magazin/index.html` | «Умный магазин» — 90 дней внедрения, вход через консультацию |
| `/o-timure/` | `o-timure/index.html` | Биография, регалии, группа компаний |
| `/instrumenty/` | `instrumenty/index.html` | Финбаланс, Taskman, «Тенге Капитал» |
| `/card.html` | `card.html` | Цифровая визитка с QR (+ `card-print.html` — макет под печать) |

**Это сайт, а не лендинг.** Меню (`.mnav` в `<nav class="mast-actions">`) и подвал-карта (`.foot-map`)
повторяются на всех семи страницах — при добавлении страницы не забудь обновить оба места
и `sitemap.xml`. Текущий раздел помечается `aria-current="page"`.

**Главная — маршрутизатор, а не витрина.** Её работа — помочь выбрать одну программу из четырёх,
поэтому на ней только герой, четыре карточки и один CTA: 6 ссылок в теле страницы вместо прежних 13.
Биография, группа компаний и инструменты вынесены на свои страницы именно поэтому — не тащи их обратно.

Исходники офферов сопровождения — docx от 08.10.2026 в `Downloads`: «Личное сопровождение.docx»
и «Бизнес-сопровождение (1).docx». Тексты страниц собраны строго по ним.

**Разводка близких программ.** «Бизнес-сопровождение» и «Умный магазин» оба B2B, поэтому на каждой
из этих страниц стоит блок с явным объяснением разницы: сопровождение — регулярная работа
с собственником, «Умный магазин» — разовое 90-дневное внедрение внутри магазина.

Общее для всех страниц: `assets/site.css` и `assets/site.js`.

**Стиль:** «Деловая газета» (editorial) — кремовая бумага, засечки, тонкие линии, акцент salmon/охра.
**Доступность:** свёрстано под скринридер (Тимур незрячий) — семантика, landmarks (включая `<nav>`),
skip-link, aria-label, декор скрыт от озвучки, уважается `prefers-reduced-motion`, внешние ссылки
предупреждают о новой вкладке. На каждой странице ровно один `h1`, уровни заголовков без пропусков.

**Контраст проверен 13.10 расчётом по WCAG, весь текст проходит AA.** Если будешь менять палитру —
не трогай `--muted-2` (#796e60, 4.53:1) и `--ochre` (#91661b, 4.64:1) в сторону светлее: прошлые
значения давали 3.82 и 4.09 и не проходили. Текст на заливке `--salmon` должен быть чистым белым
(4.76:1), цвет бумаги на ней даёт только 4.33.

**Блоки с анимацией появления** прячутся только при живом JS: класс `js` вешается инлайн-скриптом
в `<head>`, а CSS прячет `.reveal` исключительно под `.js`. Без этого любая ошибка загрузки
`site.js` оставляла страницу почти пустой.

## Что где править

**Номер WhatsApp, тексты заявок, ссылки на приложения** — `assets/site.js`, сверху:

```js
var WHATSAPP_NUMBER = "77077570443";   // Тимур Алибеков
var WHATSAPP_TEXTS  = { default, seminar, combo, magazin, lichnoe, biznes };
var APP_URL / TASKMAN_URL / TENGE_URL  // Финбалансер / Taskman / Тенге Капитал
```

Кнопка подхватывает нужный текст через атрибут `data-wa-text="magazin"` на ссылке с классом `cta-wa`.

**День и время тренинга** — `seminar/index.html`, внизу в `<script>`: `TRAINING_WEEKDAY`, `TRAINING_HOUR`.
Дата и обратный отсчёт считаются сами, руками обновлять не нужно.

**Оплата тренинга:** Kaspi QR (`kaspi-qr.png`, счёт ИП Алибеков Т.К.) → покупатель сканирует,
вводит сумму, присылает чек в WhatsApp → получает доступ.

## Google Ads

Тег `AW-18318471443` стоит на всех трёх страницах, конверсия шлётся при клике по любой кнопке
с классом `cta-wa` (см. `ADS_SEND_TO` в `assets/site.js`).

⚠️ **После переезда на хаб кампания ведёт не туда.** Финальный URL кампании семинара указывал на
`alibekov.pro` — теперь там хаб с выбором из двух программ, а не лендинг тренинга. В интерфейсе
Google Ads финальный URL нужно поменять на `https://alibekov.pro/seminar/`, иначе платный трафик
получает лишний шаг перед заявкой и конверсия просядет.

Под «Умный магазин» аудитория другая (владельцы розницы, а не частные лица) — под него имеет смысл
отдельная кампания с посадочной `https://alibekov.pro/umny-magazin/`, а не расширение текущей.

## Открытые хвосты

- **Фото Тимура** — на всех страницах плейсхолдер «ТА». Заменить блок `.photo` на `<img src="/timur.jpg" alt="Тимур Алибеков">`.
- **og.png** — есть, 1200×630, собран скриптом из типографики сайта (Playfair Display + Inter,
  кремовый фон, двойная рамка). Если появится фото Тимура — картинку стоит пересобрать с ним.
- **«Умный магазин» — чего не хватает в тексте:** реальные отзывы клиентов, сколько магазинов уже прошло
  программу, ниша магазина из кейса (цифры 700 тыс.→4,3 млн ₸ и 24,2→36,4 млн ₸ взяты из промо-материала),
  формат оплаты и рассрочка. Страница написана строго по тому, что было известно; цены и обещания не выдуманы.
- **Тенге Капитал** на хабе показан как инструмент. Если игра станет отдельным платным продуктом —
  ей нужна своя карточка в разделе «Для себя» и отдельная посадочная.
- **Телефон подтверждён 13.10:** верный — `+7 707 757 0443` (тот, что в `assets/site.js`).
  Номера из docx (`+7 701 757-04-43` и `+7 707 893-77-77`) использовать не нужно.
- **⚠️ Адрес не опубликован намеренно.** Аль-Фараби 21 из docx — неактуален (подтверждено 13.10).
  Предполагаемый общий адрес «Жибек Жолы, 64» НЕ подтверждён: в рабочих заметках он числится
  и как адрес Google Business Profile Etemia («Жибек жолы 64 офис 9»), и как адрес, который
  ранее убирали с nolabel.kz как недостоверный — именно из-за риска misrepresentation
  в Google Ads, который уже блокировал Merchant Center у Etemia. На alibekov.pro крутится
  платная реклама, поэтому до подтверждения на страницах стоит только «Алматы».

## Деплой

`git push origin main` → GitHub Pages собирает автоматически (1–2 минуты).
Домен: `CNAME` → `alibekov.pro`, DNS-зона живёт **в Cloudflare** (не в панели ps.kz — записи,
добавленные там, никуда не попадают). `.nojekyll` отключает обработку Jekyll.
