# alibekov.pro — хаб программ Тимура Алибекова

Статичный сайт без сборки и зависимостей (шрифты — Google Fonts по CDN). Деплой: GitHub Pages из `main`.

## Структура

| Адрес | Файл | Что это |
|---|---|---|
| `/` | `index.html` | Хаб: две карточки программ, ведущий, группа компаний, инструменты |
| `/seminar/` | `seminar/index.html` | Лендинг тренинга «Хватит ли вам денег на всю оставшуюся жизнь?» (3 900 ₸ / 9 990 ₸ с игрой) |
| `/umny-magazin/` | `umny-magazin/index.html` | Лендинг программы «Умный магазин» — 90 дней внедрения, вход через консультацию |
| `/card.html` | `card.html` | Цифровая визитка с QR (+ `card-print.html` — макет под печать) |

Общее для всех страниц: `assets/site.css` и `assets/site.js`.

**Стиль:** «Деловая газета» (editorial) — кремовая бумага, засечки, тонкие линии, акцент salmon/охра.
**Доступность:** свёрстано под скринридер (Тимур незрячий) — семантика, skip-link, aria-label,
декор скрыт от озвучки, уважается `prefers-reduced-motion`. На каждой странице ровно один `h1`,
уровни заголовков идут без пропусков.

## Что где править

**Номер WhatsApp, тексты заявок, ссылки на приложения** — `assets/site.js`, сверху:

```js
var WHATSAPP_NUMBER = "77077570443";   // Тимур Алибеков
var WHATSAPP_TEXTS  = { default, seminar, combo, magazin };
var APP_URL / TASKMAN_URL / TENGE_URL  // Финбалансер / Taskman / Тенге Капитал
```

Кнопка подхватывает нужный текст через атрибут `data-wa-text="magazin"` на ссылке с классом `cta-wa`.

**День и время тренинга** — `seminar/index.html`, внизу в `<script>`: `TRAINING_WEEKDAY`, `TRAINING_HOUR`.
Дата и обратный отсчёт считаются сами, руками обновлять не нужно.

**Оплата тренинга:** Kaspi QR (`kaspi-qr.png`, счёт ИП Алибеков Т.К.) → покупатель сканирует,
вводит сумму, присылает чек в WhatsApp → получает доступ.

## Google Ads

Тег `AW-18318471443` стоит на всех трёх страницах, конверсия шлётся при клике по любой кнопке
с классом `cta-wa` (см. `ADS_SEND_TO` в `assets/site.js`).

⚠️ **После переезда на хаб кампания ведёт не туда.** Финальный URL кампании семинара указывал на
`alibekov.pro` — теперь там хаб с выбором из двух программ, а не лендинг тренинга. В интерфейсе
Google Ads финальный URL нужно поменять на `https://alibekov.pro/seminar/`, иначе платный трафик
получает лишний шаг перед заявкой и конверсия просядет.

Под «Умный магазин» аудитория другая (владельцы розницы, а не частные лица) — под него имеет смысл
отдельная кампания с посадочной `https://alibekov.pro/umny-magazin/`, а не расширение текущей.

## Открытые хвосты

- **Фото Тимура** — на всех страницах плейсхолдер «ТА». Заменить блок `.photo` на `<img src="/timur.jpg" alt="Тимур Алибеков">`.
- **og.png** — картинка превью для репостов (1200×630), положить в корень. Сейчас мета ссылается на несуществующий файл.
- **«Умный магазин» — чего не хватает в тексте:** реальные отзывы клиентов, сколько магазинов уже прошло
  программу, ниша магазина из кейса (цифры 700 тыс.→4,3 млн ₸ и 24,2→36,4 млн ₸ взяты из промо-материала),
  формат оплаты и рассрочка. Страница написана строго по тому, что было известно; цены и обещания не выдуманы.
- **Тенге Капитал** на хабе показан как инструмент. Если игра станет отдельным платным продуктом —
  ей нужна третья карточка в блоке «Программы» и своя посадочная.

## Деплой

`git push origin main` → GitHub Pages собирает автоматически (1–2 минуты).
Домен: `CNAME` → `alibekov.pro`, DNS-зона живёт **в Cloudflare** (не в панели ps.kz — записи,
добавленные там, никуда не попадают). `.nojekyll` отключает обработку Jekyll.
